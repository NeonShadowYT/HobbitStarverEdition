THIS IS VERY EASY, don't worry!

------------
INSTALLATION 
------------
To run multiplayer you will have to download the unpacked version of the Hobbit. 
You can find it here: https://github.com/hobbit-kingdom/hobbit-versions/releases/tag/Unpacked

Then copy the contents of "THE SYNCHRONY" folder to the main Hobbit Directory. Accept all the overrides.

Run the MultiplayerSetup.exe. You can delete it after.

Congrats - Multiplayer was successfully set up.

---------------
OPTIONAL
---------------
If you want The Hobbit to run in Windowed mode copy Meridian.exe from WINDOWED folder and put it in the root of your game.

---------------
How to Play
---------------
Now you will need to either be on the same local network, or download app like RadminVPN. I recommend RadminVpn.

Inside RadminVpm create a network. Ask your friends to connect to it (network can be created by anyone, it doesn't matter).

Now decide who will be the host. Everyone should copy host IPv4 from the RadminVpn and put it inside the synchrony_config.txt (including host!). 

Now the host should run server.exe.

After that everyone can start launching the game. Run the HobbitLauncher.exe to run the game in multiplayer mode.
You will see a window which will prompt you if you are the host or not. Select your role and then press Done.

You are done! Launch any level and your friends should appear!

Tips
---------------
Press / to open the chat window. On /help you can see available commands.
You can also chat in the game if sending message without /.
If you want to see debug logs put debug=1 in the config.
Edit launcher_config.txt to specify if you want to autorun The Hobbit Kingjoyer by putting kingjoyer=1.
OLDER SAVE FILES WILL NOT HAVE OTHER BILBO'S SHOW UP! Don't use older save files that was made before you installed the mod.

---------------
Troubleshoot
---------------
If you don't see someone appear go back to the main menu and start the level again/reload the level (try both).
If something doesn't work ask your friend to host the game or restart the server.exe and the game itself.
If something more doesn't work tag us at the Discord.
The Gathering of the Clouds level was NOT tested, if you encounter any issues let us know.
